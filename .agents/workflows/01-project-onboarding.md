# Project Onboarding
1. Inspect Git status/branch and preserve uncommitted work.
2. Read rules, README, manifests, lockfiles, CI and deployment config.
3. Map frontend, backend, database, auth, integrations and deployment.
4. Identify test/lint/typecheck/build commands.
5. Run safe baseline checks where possible.
6. Update `docs/engineering/PROJECT_OVERVIEW.md` from observed facts.
7. Separate confirmed facts, assumptions and unknowns.
8. Do not modify application code unless requested.
