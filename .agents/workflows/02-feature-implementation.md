# Feature Implementation
1. Define user-visible outcome and acceptance criteria.
2. Inspect existing implementation and callers.
3. Identify authorization, data ownership, privacy and failure cases.
4. Plan the smallest safe change and dependencies.
5. Implement using existing conventions.
6. Update server contracts, consumers, persistence and docs together as needed.
7. Add suitable tests.
8. Run focused and broader checks.
9. Inspect the full diff for unrelated changes and secrets.
10. Report changed files, actual commands/results and remaining risks.
Ask before destructive or externally impactful operations.
