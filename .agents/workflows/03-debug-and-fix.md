# Debug and Fix
1. Capture exact expected/actual behavior and reproduction steps.
2. Reproduce or state why blocked.
3. Trace the full execution path.
4. Test hypotheses with evidence.
5. Add a failing regression test when practical.
6. Fix root cause with the smallest safe change.
7. Run regression and related suites.
8. Inspect adjacent behavior and diff.
9. Report root cause, fix, evidence and unknowns.
